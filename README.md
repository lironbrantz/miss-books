# 📚 Miss Books

A simple book management app built with React as part of the Coding Academy course.

### Features
- Add, edit, and delete books
- Search and filter books using URL query params
- View book details and add reviews
- Search and add books using Google Books API
- Dashboard with category statistics using Chart.js
- Dynamic rating components: Select, Textbox, and Stars

### Built With
React · React Router · JavaScript · CSS · Chart.js · LocalStorage

### Getting Started
Clone the repository and open `index.html` using Live Server.
